# Phlix trademark policy

The Phlix **code** is open source under the [Mozilla Public License 2.0](LICENSE).
The Phlix **name and logo** are separate from the code licence and are not granted
by it. This page says plainly what you may and may not do with them.

This exists so that "Phlix" keeps meaning this project. It is not intended to
restrict anyone's use of the software.

## What the MPL already gives you

The licence covers the code and is unaffected by anything here. You may use,
modify, self-host, redistribute, embed in a larger product, and sell services
around Phlix Server, subject only to MPL-2.0 (§2, §3) — chiefly that if you modify
a Phlix source file, that file's source stays available under MPL-2.0.

## You may, without asking

- Say that your product, plugin, client, or service **works with**, **is built
  on**, **is compatible with**, or **is powered by** Phlix.
- Use the name in truthful descriptive statements — "a Phlix plugin for
  Last.fm", "Phlix hosting", "an unofficial Phlix client for tvOS".
- Use the name and logo in articles, talks, reviews, tutorials, comparisons, and
  documentation.
- Keep the name in an **unmodified** redistribution — packaging Phlix Server for a
  distro, a container image, or an appliance.
- Use the logo to link to this project.

## Please ask first

- **Modified distributions under the Phlix name.** If you ship a fork with
  functional changes, please pick your own name. You may and should say it is
  "based on Phlix" or "a fork of Phlix" — just don't present it *as* Phlix, so
  users know whose bugs they are reporting.
- **Names that read as official** — `phlix-official`, "Phlix Pro", "Phlix
  Enterprise", "Phlix Cloud", or a domain like `phlix-<something>.com` presented
  as the project's own.
- **Merchandise** carrying the name or logo.
- **A modified logo**, or the logo altered to suggest a different product.

## Please don't

- Imply endorsement, sponsorship, certification, affiliation, or partnership that
  does not exist.
- Register "Phlix", a confusingly similar mark, or a matching social handle as
  your own.
- Use the name or logo in a way that suggests your modified version is the
  canonical one.

## Attribution

Attribution is **appreciated but not required** — MPL-2.0 requires only that you
preserve the licence notices already in the source files (§3.4), and nothing here
adds a requirement to display anything in your user interface.

If you would like to credit the project, "Powered by Phlix" with a link to the
repository is perfect.
